## 注记

### 已解决的关键澄清

1. **FR-011 认证与密钥管理**
   - **原需求**：具体签名/私钥托管方式、钱包连接方案需确认
   - **解决方案**：永不在后端存储私钥；用户通过 RainbowKit + wagmi 钱包签名派生 API Key；Key 存储在前端会话；后端仅使用预批准 Key 执行
   - **优势**：零私钥泄露风险，满足监管，用户完全控制

2. **P1 运行模式**
   - **原不确定**：是否支持自主模式（后端无人值守生成密钥与下单）
   - **决策**：P1 仅交互模式，所有关键操作需用户前置批准；自主模式不进 P1，可在 P3 作为可选探索
   - **理由**：降低复杂度，优先确保安全与可控性
